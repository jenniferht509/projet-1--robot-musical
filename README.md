# projet-1--robot-musical
Le robot joue une gamme musicale complète (Do Re Mi Fa Sol La Si Do) tout en tournant sur lui-même. 

Modifications: Chaque note déclenche une forme lumineuse (cœur, visage, losange, etc.) sur l’écran LED.  Les moteurs du cuteBot tournent pendant la mélodie puis s’arrêtent.  Bouton A démarre la boucle infinie, bouton B l’arrête proprement.
